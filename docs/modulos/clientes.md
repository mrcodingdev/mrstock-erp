# Módulo de Gestão de Clientes

**Arquivos:** `clientes/index.php`, `clientes/functions.php`  
**Acesso:** Exclusivo para Administradores (`admin`)  
**Objetivo:** Cadastro e acompanhamento de clientes pessoas físicas e jurídicas (escolas, escritórios, empresas), histórico de compras e comunicação direta via WhatsApp.

---

## 1. Funcionalidades da Interface

- **Live Search Instantâneo:** Busca por nome, CPF/CNPJ, telefone ou e-mail.
- **Link Direto para WhatsApp API (`wa.me`):** Botão verde que abre a conversa com o cliente no WhatsApp Web ou App com um único clique.
- **Menu de Ações Flutuante (`.so-actions-btn`):** Edição rápida, histórico de pedidos e exclusão segura.
- **Validação de Documentos:** Suporte a CPF e CNPJ formatados.
