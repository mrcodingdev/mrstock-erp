# Onde encontrar os arquivos do MrStock

Mapa da documentação e das ferramentas do MrStock após a organização de 30/10/2026.

| Conteúdo | Local |
|---|---|
| Código PHP, CSS, JS e imagens usados pelo sistema | Pastas originais da aplicação, preservadas |
| Manual oficial e documentos vinculados pelo site | [Centro de documentação](README.md) |
| Testes de regressão | [tests](../tests/) |
| Entregas, patches e revisões anteriores | [handoffs](handoffs/README.md) |

No ambiente local, consulte `docs/contexto/` para dossiês, `docs/diagramas/` para diagramas e `docs/analises-geradas/` para saídas de análise. Os geradores do manual ficam em `scripts/documentacao/` e o validador de restauração em `scripts/manutencao/`.

O cofre ativo fica em `04_Base_de_Conhecimento_e_Obsidian/07_Megabrain_Obsidian/`. O mesmo diretório-base reúne `Historico_Versoes/2026-10-30/` para versões anteriores e `Repositorios_Uteis_Vibecoding/` para estudos de ferramentas. Fontes DOCX e Markdown e suas exportações PDF foram mantidas.

O pacote histórico `MrStock.zip` foi preservado em `C:\xampp\MrStock_Arquivos\Pacotes_Historicos`, fora da raiz web.
