# Política de Segurança

## Versões Suportadas

Apenas as versões estáveis listadas abaixo recebem atualizações ativas de segurança:

| Versão | Suporte de Segurança |
| :--- | :--- |
| 2.2.x | :white_check_mark: Ativo |
| 2.1.x | :x: Encerrado |
| < 2.0 | :x: Encerrado |

## Relato de Vulnerabilidades

Para relatar uma vulnerabilidade de segurança:
1. Não abra uma issue pública.
2. Utilize o recurso oficial GitHub Private Vulnerability Reporting na aba Security deste repositório.
3. Se preferir contato direto com a equipe técnica: contato@mrstock.com.br.

### SLA de Resposta e Correção
* Confirmação inicial do relato: até 48 horas úteis.
* Avaliação de impacto e triagem: até 5 dias úteis.
* Disponibilização de patch corretivo: até 15 dias corridos.
